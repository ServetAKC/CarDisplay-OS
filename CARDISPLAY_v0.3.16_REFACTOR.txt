Car Display OS v0.3.16 - Structure, correctness and tests

No new user-facing features. This release is about making the next feature
cheap to add and the existing behaviour verifiable.

Structure
- cheapYellowLCD went from 3444 lines to ~900. Cover caching, backlight and
  the visualizers are now their own modules with their own headers.
- The sixteen visualizer modes are one table. The enum, the name switch, the
  dispatch switch and the "style >= CYBER_GRID" range test are gone.
- Headers that defined globals became .h/.cpp pairs, so the power-cycle flag
  and the touch state are single objects rather than one copy per file.
- Touch publishes a single TouchAction enum instead of eight booleans.
- The version number lives only in version.h.

Correctness
- millis() comparisons are rollover-safe. Polling, the progress bar, the touch
  cooldown and the visualizer peak decay would all have wedged permanently
  after 49.7 days of continuous power.
- Total silence now produces a completely dark visualizer. The mid and treble
  lifts add a constant offset and ran after the silence gate, so bands 8-15
  sat at a permanent level of 1-2 with no sound at all.
- The Wi-Fi connecting animation is stopped by handshake. The old code
  force-deleted the task after 250 ms, which could destroy a task holding the
  display SPI lock and deadlock every later draw.
- Cover downloads have a hard size cap and cannot fill the card.
- strcpy on network data replaced with a bounded copy that cannot drift away
  from its buffer.
- Config writes no longer serialise into a file handle that failed to open.
- Coordinates typed into the setup portal are validated; a blank or malformed
  field keeps the previous value instead of snapping to 0,0.

Configuration
- Spotify market, timezone and the sunset coordinates moved from compile-time
  #defines to the setup portal. They were pinned to Ireland and Sofia.
- New defaults: market TR, timezone <+03>-3, Istanbul. Older config files load
  unchanged and pick up these defaults for the new fields.

Performance and memory
- FFT twiddle factors are precomputed into a 1 KB table instead of being
  generated by repeated complex multiplication inside the butterfly loop.
- Built with -O2 instead of the default -Os.
- The visualizer hands back the idle queue-prefetch TLS session before
  allocating its 64 KB frame buffer.
- startWrite/endWrite are skipped when drawing into the sprite. They are not
  virtual in TFT_eSPI, so they were opening a real SPI transaction against the
  panel for drawing that never reached it.

Duplication removed
- The two ~90-line cover download loops are one parameterised transfer.
- Eight JPEGDEC callbacks became four shared ones plus two open adapters.
- The pulse ring no longer redefines the palette it shares with the theme.

Tests
- test/test_native covers the rollover arithmetic, the bounded copy, the FFT
  and band mapping, the noise gates, and sunrise/sunset against published
  times for Istanbul.
- pio test -e native (host) or pio test -e esp32_test (on the board).

Repository
- The project is now a git repository. v0.3.15 is tagged, so any of this is
  revertable and diffable rather than living in a folder copy.
